# 🌱 Sustainable Fertilizer Optimizer

Smart fertilizer recommendations for efficient, economical and sustainable farming.

## 🚀 Live Demo

👉 [Open the Live Application](https://sustainable-fertilizer-optimizer-wzdjo5fl8wdahjsxygrnex.streamlit.app/)

## 🌾 Features

### 🌾 Crop Analysis
Select a crop and understand its fertilizer requirements.

### 🧪 Soil Analysis
Enter Nitrogen, Phosphorus and Potassium values to analyze soil nutrients.

### 🌱 Fertilizer Optimizer
Calculate recommended quantities of:
- Urea
- DAP
- MOP

## 🌍 Sustainable Agriculture

The application helps optimize fertilizer usage and avoid unnecessary nutrient application.
